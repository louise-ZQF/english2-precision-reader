# 考研英语二本地版

在线版部署到 GitHub Pages：[打开英语二精翻](https://louise-zqf.github.io/english2-precision-reader/english/)。源代码仓库为 [louise-ZQF/english2-precision-reader](https://github.com/louise-ZQF/english2-precision-reader)，推送 main 分支会自动更新网站。在线版没有 Python 服务，阅读、精翻、收藏、长难句练习和文件导入导出都在浏览器中完成；反馈和纠错只保存到当前浏览器。设备间迁移使用备份文件，不提供扫码中转。在线 PDF 详解沿用原站下载链接，题库、词典、精翻资料和练习代码由 GitHub Pages 提供。本地网址和线上网址分别保存学习记录，需要通过“数据”导出、导入迁移。


已增加桌面精翻：右上角“进入精翻”开启后，单击词语查义、双击收藏，悬停不弹释义；正文保留原有自然段、字号、行距和连续阅读排版，句子编号嵌在行内，不逐句另起一行。点编号翻译并查看主干、从句、插入说明和修饰连接，同一结构越过插入成分后用同色、同号和“续”标记接回。顶栏中央提供当前试卷 Text 1—4 跳转入口，滚动时保持可用，切换年份后自动对应新试卷。固定搭配作为词组识别、显示和收藏，背词也支持完整词组。连字符词（如 cavity-preventing）和含撇号的词按原文完整拼写显示、查义和收藏，不沿用句法分析器拆开的子词；词典没有完整词条时使用整词在线翻译，不拿其中一部分的释义代替。

精翻中可划选任意长度原文，点浮动工具栏翻译，或右键“收藏到长难句”；翻译、结构和收藏后的练习都严格使用实际选区，不会补全到所在整句。完整命中的本地译文直接使用，其余选区通过 MyMemory 在线翻译，失败时尝试 Google 翻译，只发送选中的文字；收藏中已经取得的选区译文会随备份保留。顶部“长难句”入口提供列表、原文定位和独立练习，可先写译文，再对照参考译文与结构并安排复习。选区、出处、练习草稿和进度保存在本机，备份导入导出也包含这些内容。

每篇完形、阅读 Text 1—4、Part B 和翻译文章的标题旁都有“已翻译”勾选项及“笔记 / 错题”入口。顶部“学习记录”提供按年份 × 文章排列的翻译热力图、可搜索和筛选的错题本及文章笔记；格子显示完成状态、错题数及是否有笔记，可直接打开对应记录或回到原文。阅读与完形题旁可点击“记错题”，记录自己的答案、核对后的正确答案、错因、复盘笔记和是否已订正；文章笔记与错题输入后自动保存，单纯打开表单不会创建错题。新增记录保存在 english2_study_records_v1，包含在“数据”的备份导入导出中；旧备份没有该字段时不会清空现有学习记录。题库未提供标准答案，正确答案由用户核对详解后填写。

语境义结合本句词性、已有中文译文和明确词汇规则筛选，无法可靠确定时标成“候选义”，可点“改本句释义”校正。句法资料使用 [spaCy 依存分析](https://spacy.io/usage/linguistic-features#dependency-parse) 离线生成，复杂结构仍可能有误；未匹配到的译文会明确提示。日常运行不需要安装 NLP 包或配置 AI API。

查词弹窗会先显示，再查询缺失释义，不会因在线接口等待而毫无反馈。常见复合词（含 right-brained、cavity-preventing）已有随脚本提供的中文释义；完整固定搭配表也在 JSON 词库加载前可用，识别支持 spinning/spun 等词形及部分可分离动词短语。2015 年 Text 3 的职场用语另有逐语境校正，如 spinning off examples（接连举出例子）、vision（愿景）、bandwidth（时间和精力余量）。界面将核对过的本文义、语法作用、完整词义及未核对的参考义明确区分；这些修订也用于对应生词本释义。其他文章的自动匹配仍需结合上下文核对，不能视为已经逐词校勘。

2015 年 Text 3 的 17 句译文已逐句按上下文重译，修正时间比较方向、比喻义、中文语序和遗漏信息；相关片段也有对应译文，维护在 public/english/js/reviewed-translations.js。精翻、原文例句和长难句练习优先采用该表，并覆盖相同选区先前缓存的机译；用户自己填写的参考译文保持原样。只在英文选区完全匹配时使用校正表，不扩展到选区外的句子；未校正内容仍标为参考译文。

单词弹窗不再自动展示整句原文和译文，改为原形、本文义、其他常见义及相关词形。例如 boundaries 显示原形 boundary、当前为名词复数，并列出 boundaries；动词和形容词可显示已收录的过去式、过去分词、现在分词、第三人称单数、比较级和最高级，动词词组也支持相应形式。词形由现有英语二真题的标注结果及确认的常用不规则变化编译，运行 .venv/bin/python scripts/build_word_forms.py 可更新 public/english/js/word-forms.js；未收录的词形不会按拼写硬造。

单词语境义已增加独立的常用义表和按原文具体位置生效的搭配校正，结合本句词性、语法关系和整句译文取义，避免直接套词典首义。明确搭配、译文匹配、普通常用义与待核对参考义分别标注；同一句里同一词的不同用法分别处理。新版义项同步用于查词、生词本列表和背词，用户自己的校正优先。词义数据维护在 public/english/js/context-senses.js，核对范围与词典来源见 reference/context-sense-review.md。运行 python3 scripts/build_precision_browser.py 更新本地文件模式的精翻资料，使直接打开 index.html 时也能读取分句、词性和译文；其他功能仍推荐使用启动脚本或在线版。

新增功能主要在 public/english/js/precision.js 与 public/english/css/precision.css；分析资料在 public/english/data/precision。修改脚本后运行 python3 scripts/refresh_versions.py 可更新资源版本，不会覆盖功能。请勿再运行初次还原用的 scripts/prepare.py，它会覆盖 app.js 的定制修改。


这是 https://study.aseeker.bio/english/ 的英语二桌面复刻工程，保留原站公开提供的 HTML、CSS、图片、可读 JavaScript、FSRS 背词程序、词典和翻译句库，并补写了独立运行所需的本地服务。它可以继续修改和增加功能，不依赖作者的 GitHub 仓库。

双击同目录的 **启动英语二.command** 即可打开。当前默认地址是 **http://127.0.0.1:8766/english/**；再次双击会复用已经启动的服务，端口被其他程序占用时会自动选用后续端口。启动窗口需要保持打开，按 Ctrl+C 可以停止。不要直接双击 index.html，浏览器会限制 JSON 文件加载。此工程只需要现有的 Python 3，不需要安装 Node 或 npm 依赖。

本地版只保留 **2010—2026 年英语二的 17 套真题、17 份 PDF 详解、4,358 个英语二词条详情页**，已移除英语一和专业课入口。原站桌面的布局、配色、字号、单词释义气泡、收藏、单词本、复制、备份导入导出、划选翻译和间隔重复背词均沿用其公开实现，页面样式和背词引擎原文件保存在 reference/upstream 中。词条详情页和高频词表中的出处、累计频次及例句已限制为英语二；通用词典和按句检索的翻译库仍保留原始内容，以避免丢失词形与义项。

收藏单词和背词进度保存在当前浏览器的 localStorage 中，同一个网址在不同浏览器中是两份独立数据；原站已有收藏不会自动迁入，可以在原站使用“数据 → 导出数据”，再在本地版导入。反馈和纠错只保存至本机的 .local-data/local.sqlite3，不会发给原站作者，成功提示也已注明“保存在本机”。扫码中转接口按前端协议重写为本地的 24 小时一次性备份接口，默认只监听本机地址。

核心阅读、词典、已收录的逐句翻译、收藏、背词以及 PDF 下载可以离线使用。有道在线发音和必应翻译外链沿用原站方案，需要联网；在线音频失败时回退到浏览器自带朗读。原站的远程访问统计、设备登记和搜索引擎提交脚本已去除。原始服务器的私有程序、管理员系统和数据库不属于可获取的前端文件，本地服务根据公开前端的请求与返回格式独立实现，并非作者私有后端源码。

后续修改主要在 public/english/js/app.js（阅读、查词、收藏、翻译及备份）、public/english/js/srs-panel.js（背词界面）、public/english/js/srs-engine.js（背词调度）、public/english/css/style.css（原站样式）以及 server.py（本地 API）中进行。题库在 public/english/data/exam_*_english2.json，资料在 public/english-materials。修改 app.js 后，应把其 MD5 的前 10 位同步写入 data/version.json 的 app 字段以及 index.html 引用 app.js 的 v 参数，避免原程序的旧版本刷新检查发生误判。

scripts/capture.py 和 scripts/capture_word_pages.py 用于记录原站公开资源，scripts/prepare.py 用于从 reference/upstream 重建本地适配。**普通使用和继续开发无需运行这些脚本**；重新运行 prepare.py 会覆盖 public 中的相应修改，所以增加功能时直接编辑 public，并先保留自己的更改。

reference/local-scope.json 记录交付范围，reference/public-resources.json 记录实际保留资源的来源与 SHA-256。本工程只做还原和英语二范围调整，没有重新校勘原站题文、答案或机器翻译。网站界面、图片和整理内容的来源保留为原站，词典元数据标明 ECDICT 1.0.28（MIT），背词包内保留其上游说明。

按本次要求，仅做了必要的桌面核对：页面加载、年份切换、悬停查词与收藏、背词释义及评分入口；未进行手机测试或建立大型测试套件。
